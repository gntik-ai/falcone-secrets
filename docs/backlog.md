# Epics and user stories

Generated by `python3 tools/build_docs.py`. S/M/L are relative complexity, not calendar promises. P0 = decisions and qualification; P1 = core; P2 = integrations and hardening; P3 = migration. Phase is the earliest stage, subject to dependencies.

Epics, parent links and task lists express hierarchy; no native GitHub sub-issues or Project board is implied. Each stable SEC identifier maps to an issue in github-issues.json.
